# Adapters

Deployment adapters live under `@reckona/mreact-router/adapters/*`. Use Node for servers and containers, edge for generic Request/Response runtimes, Cloudflare for Workers, AWS Lambda for API Gateway and Function URLs, and static for prerendered export.
