# Environment variables reference

Framework-level variables include `PORT`, `HOST`, `MREACT_ROUTER_LOG`, `MREACT_ROUTER_HOST_POLICY`, `MREACT_ROUTER_ALLOWED_HOSTS`, `MREACT_SERVER_ACTION_SECRET`, and `NODE_ENV`.

Application-specific variables should be documented by the app. Treat secrets as server-only unless a page intentionally serializes a public value.
