# Mreact documentation

Mreact is a compiler-first, React-flavored framework for building server-rendered applications that only ship client JavaScript where a route needs it. The docs are organized around the path a developer follows: understand the model, build features, deploy safely, then look up exact APIs.

## Status and limitations

Mreact is experimental. APIs may change before `0.1.0`, and some areas are intentionally conservative: client boundary inference follows supported static shapes rather than arbitrary program semantics, MDX is integrated through Vite plugins rather than native `page.mdx` routes, and production authentication examples are starter patterns rather than complete identity-provider integrations.

## Reading path

- Start with Getting Started if you want to create and run an app.
- Use Guides when you are implementing routes, APIs, auth, metadata, CSS, or deployment-sensitive behavior.
- Use Deployments when you are preparing production output, GitHub Pages, Cloudflare, Lambda, containers, source maps, logging, or CDN assets.
- Use Reference when you need exact option names, route exports, adapter APIs, or environment variables.
