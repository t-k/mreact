# Host policy and proxies

For public deployments, configure exact `allowedHosts` and prefer `hostPolicy: "strict"`. Use trusted proxy mode only when your reverse proxy normalizes forwarded host and proto headers before traffic reaches mreact.

Host policy affects absolute URLs, redirects, cache keys, metadata routes, and security-sensitive origin decisions.
