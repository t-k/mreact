# Static hosting

Static hosts serve prerendered route HTML and copied client assets. Use `exportStaticApp()` after `mreact-router build`, write `.nojekyll` for GitHub Pages, and provide a root-level `404.html` when the host supports it.

Only prerendered routes are exported. Dynamic runtime APIs need a server, Worker, or Lambda target.
