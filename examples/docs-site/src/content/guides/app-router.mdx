# App Router

The app router maps files under `app/` or `src/app/` to pages, layouts, route handlers, middleware, and metadata conventions. It is the main entry point for building full Mreact applications.

## What to learn here

- How route files become URLs.
- How pages, layouts, templates, loading states, errors, and not-found boundaries compose.
- How server-rendered routes stay JavaScript-free until client behavior is detected.
- How deployment adapters run the same built app on Node, Cloudflare, Lambda, containers, and static hosts.
