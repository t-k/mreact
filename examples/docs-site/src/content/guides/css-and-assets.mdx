# CSS and assets

Import CSS from pages, layouts, or templates to emit route stylesheet assets. Public files live under `public/` and are copied into the built client output. For docs-style sites, Tailwind can be wired through the Vite plugin and a single layout-level CSS import.

For production CDN hosting, configure `assetBaseUrl` for built route assets and `publicAssetBaseUrl` for public asset helpers.
