# Cookies and sessions

Use cookie helpers for low-level HTTP cookie handling and `@reckona/mreact-auth` session helpers for session lifecycle. Production session cookies use secure defaults such as `HttpOnly`, `SameSite=Lax`, and secure names when `NODE_ENV=production`.

Use a durable session store for real production deployments.
