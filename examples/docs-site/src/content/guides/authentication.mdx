# Authentication

`@reckona/mreact-auth` builds on router sessions and adds role and permission guards. Use `requireSession`, `requireRole`, or `requirePermission` inside loaders and route handlers.

The examples use memory sessions and demo credentials. Production apps should replace those with a durable store, real password or OIDC flow, rotation policy, and deployment-managed secrets.
