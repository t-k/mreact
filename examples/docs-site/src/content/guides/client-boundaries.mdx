# Client boundaries

Mark an island with `.client.tsx` or a top-level `"use client"` directive. Server-renderable children remain visible in the initial HTML where possible, so content can paint and be indexed before hydration.

The analyzer follows supported static render shapes. For dynamic registries or hidden dispatch, use explicit route configuration.
