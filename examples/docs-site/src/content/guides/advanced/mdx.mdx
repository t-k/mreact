# MDX

mreact supports MDX-style content through Vite plugins. Import `.mdx` files from TypeScript route modules or registries, then prerender the route output. Native `page.mdx` route files are not the expected convention.

This docs site uses MDX content files plus a catch-all route that imports a registry of available pages.
