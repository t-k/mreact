# Route handlers

`route.ts` files expose HTTP method functions such as `GET`, `POST`, `PUT`, `DELETE`, and `ALL`. Handlers return standard `Response` objects and can receive decoded route params as the second argument.

Throwing a `Response` is useful for guard helpers that need to stop execution immediately.
