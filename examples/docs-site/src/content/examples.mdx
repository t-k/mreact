# Examples

Use examples to copy working project shapes rather than isolated snippets.

- `examples/app-router`: router tour with layouts, metadata, client boundaries, streaming, actions, cache, handlers, middleware, auth, i18n, and analytics.
- `examples/hacker-news`: read-only app-router example deployed to Cloudflare Workers.
- `examples/reactive-primitives`: low-level reactive primitive examples.
- `examples/store`: store selectors, transactions, and subscriptions.
- `examples/ssr-streaming`: SSR primitives without the app router.
- `examples/docs-site`: this documentation site, including MDX content and GitHub Pages static export.
