store

Three minimal demos of @reckona/mreact-store — a centralized state container built on the reactive primitives. All three pages share a single store instance from src/store.ts, so changes made in one tab show up in the others.

  • /cart.html — createStore + set / update / replace
  • /selectors.html — store.select((state) => slice)
  • /subscribe.html — store.subscribe((next, previous) => ...)
