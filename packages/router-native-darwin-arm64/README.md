# @reckona/mreact-router-native-darwin-arm64

Platform package for `@reckona/mreact-router-native` on macOS arm64.

This package contains the native `index.node` addon for:

- `os`: `darwin`
- `cpu`: `arm64`

Applications should not import this package directly. Install
`@reckona/mreact-router-native`; it selects the matching optional dependency at
runtime.
